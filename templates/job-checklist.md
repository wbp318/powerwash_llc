# Job Checklist

Print this, laminate it, zip-tie it to the trailer.

## Night before
- [ ] Confirmation text sent (time, water on, cars moved, windows shut, pets in)
- [ ] Washer: oil checked, gas full, spare gas can full
- [ ] Pressure hose, garden hose, quick connects, spare tips, turbo nozzle
- [ ] Surface cleaner
- [ ] Downstream injector + chem hose + filter
- [ ] J-rod / soap tips, extension wand
- [ ] SH mixed (bucket, lid on, labeled), surfactant, degreaser
- [ ] Pump sprayer filled with water
- [ ] Tarps, clamps, plastic for outlets
- [ ] PPE: respirator, goggles, gloves, boots, long sleeves
- [ ] First aid kit, eyewash
- [ ] Ladder (if gutters / 2-story)
- [ ] Yard sign, business cards
- [ ] Phone charged, Square reader

## Arrival
- [ ] Walk property with customer, confirm scope and price
- [ ] Before photos: every elevation, driveway, any existing damage (close-ups)
- [ ] Locate spigot, test water pressure
- [ ] Locate electrical panel, outlets, doorbell cams, light fixtures: cover
- [ ] Cars moved, windows closed, pets inside
- [ ] Pre-wet plants and grass

## During
- [ ] Chem low to high, dwell, never let it dry
- [ ] Rinse high to low
- [ ] Surface cleaner: steady pace, 50% overlap, edge with 25°
- [ ] Rinse plants again
- [ ] Rinse windows last
- [ ] Debris to grass, not street drain

## Finish
- [ ] Walk with customer
- [ ] After photos, same angles as before
- [ ] Collect payment, send receipt
- [ ] Ask for review (send link tonight) and referrals (hand 3 cards)
- [ ] Yard sign placed (1 week)
- [ ] Remove tarps and outlet covers, coil hoses, check nothing left behind

## Tonight
- [ ] Review link texted
- [ ] Before/after posted to Facebook
- [ ] Job log updated: sq ft, time on site, chem used, price, notes
- [ ] Mileage logged
- [ ] Injector flushed with clean water, pump drained if freezing
- [ ] Restock chem for tomorrow
